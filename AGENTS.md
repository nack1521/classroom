Verify the connection URLs resolve to the local machine and reject hosted URLs, Content Planner labels/volumes, or any unexpected target. Before any write-capable Docker/Supabase command, independently verify the selected target's identity, mounts/volumes, Docker Compose provenance, port bindings, and connection settings. If isolation cannot be established, stop as BLOCKED rather than switching databases. Do not reset an existing stack or clean up records not created by the test.

Do not run `supabase link`, remote pushes, or hosted role provisioning in a local test handoff; keep real student data outside it. Never change Content Planner's database or containers to repair Classroom.

Full-stack integration tests must independently fail closed without the verified local project/DB/API targets. Reports must identify which target was used and distinguish PostgreSQL fixture evidence from actual local Auth→PostgREST integration and still-unverified Google/hosted boundaries.

Workspace rules guide agent behavior; they do not restrict Docker daemon permissions. An operator must still review the target before granting tool execution.
